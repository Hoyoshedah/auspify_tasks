# Auspify Technologies Internship Tasks

Machine learning tasks completed on the Netflix titles dataset. Each folder contains its own notebook, README, report, and supporting files.

- **Task1_Netflix_Recommender**: Content-based recommendation system
- **Task2_ContentTypePrediction**: Movie vs TV Show classifier
- **Task3_Audience_Rating_Classification**: Audience rating classifier
- **Task4_Content_Segmentation**: K-Means clustering of titles
